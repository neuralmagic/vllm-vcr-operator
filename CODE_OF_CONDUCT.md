# Code of conduct

This project follows the [Contributor Covenant, version
2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, critique code rather than people, and
do not tolerate harassment of any kind.

Enforcement: report incidents privately to the maintainers through a GitHub
security advisory or by contacting the maintainers listed in `CODEOWNERS`. Reports
are handled confidentially. Maintainers may edit or remove contributions and, for
repeated or serious violations, temporarily or permanently ban contributors.
